# Default time-to-event statistics shown in the module

Includes descriptive Mean (SD) of `AVAL` plus Kaplan-Meier median (95%
CI), quartiles, and range.

## Usage

``` r
default_ttni_surv_stats()
```

## Value

Character vector of statistic names from
[`ttni_surv_time_choices()`](https://ygma-bitc.github.io/tm.ttni/reference/ttni_surv_time_choices.md).
