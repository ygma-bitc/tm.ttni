# Default TTE footnotes

Default TTE footnotes

## Usage

``` r
default_ttni_footnotes(compute_hr = FALSE, conf_type = "log-log")
```

## Arguments

- compute_hr:

  `logical(1)` Whether inferential statistics are shown.

- conf_type:

  `character(1)` KM confidence-interval type.

## Value

Character vector of footer notes.
